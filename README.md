# Игра «Alies»

**Alies** — настольная словесная игра, в которой игроки или команды объясняют случайные слова, не используя однокоренные слова и сам ответ. Цель игры — набрать как можно больше очков за ограниченное время, правильно угадывая слова.

---

## 🎮 Управление

| Действие                   | Управление                                         |
| :------------------------- | :------------------------------------------------- |
| **Выбор режима**           | Кнопки **«Одиночная игра»** / **«Командная игра»** |
| **Подтверждение настроек** | ЛКМ                                                |
| **Угадано**                | Кнопка **«Угадано»**                               |
| **Пропустить слово**       | Кнопка **«Пропустить»**                            |
| **Справка**                | Кнопка **«Ход игры»**                              |
| **Возврат в меню**         | Кнопка **«В меню»**                                |
| **Выход из игры**          | Кнопка **«Выйти»**                                 |

---

## Ключевые механики

1. **Два игровых режима:** одиночная игра и командное соревнование.
2. **Настройка партии:** возможность изменить имя игрока или название команды перед началом игры.
3. **Выбор цвета:** каждому игроку или команде можно назначить индивидуальный цвет фишки.
4. **Случайная выдача слов:** слова выбираются случайным образом из встроенной базы.
5. **Подсчёт очков:** за каждое правильно угаданное слово начисляется одно очко.
6. **Пропуск слов:** возможность пропустить сложное слово без остановки игры.
7. **Автоматическая смена слов:** после угадывания или пропуска отображается новое случайное слово.
8. **Таймер раунда:** игровой процесс ограничен по времени.
9. **Таблица результатов:** текущий счёт игроков или команд отображается в режиме реального времени.
10. **Подсветка активного игрока:** текущий игрок выделяется выбранным цветом.
11. **Сохранение результатов:** очки предыдущих игроков и команд не теряются при смене хода.
12. **Обновление базы слов:** после использования всех слов автоматически начинается новый круг.
13. **Окно помощи:** кнопка **«Ход игры»** открывает подробное описание правил и механик без выхода из партии.
14. **Главное меню:** быстрый переход между игровыми режимами, правилами игры и выходом из приложения.
15. **Удобный интерфейс:** простой и понятный дизайн, не требующий дополнительного обучения.
16. **Автоподстановка имени:** при пустом вводе автоматически используется стандартное имя «Игрок».
17. **Плавная навигация:** переходы между экранами происходят без перезапуска приложения.
18. **Полный сброс партии:** при возврате в главное меню текущая игровая сессия начинается заново.

## Инструкция по запуску

### Через исполняемый файл (Windows)

1. Перейдите в папку `dist`.
2. Запустите **`Alies.exe`**.

*Для запуска не требуется установка Python — все необходимые ресурсы уже включены в исполняемый файл.*
